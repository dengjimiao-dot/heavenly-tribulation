## 2. 一句话

**在劫季倒计时下经营危门、外出秘境锁卡组作战，用业力与仙命把「天道」写成可玩的压力。**

## 3. 主循环

```text
开局领危门
  → 劫季倒计时（雷月 / 雾月 / 血月）
  → 白天经营：产牌胚与渡劫资源
  → 出门秘境：进门锁卡组，肉鸽战斗
  → 战利品：词缀牌 + 业力（可洗入牌库的债/赌）
  → 季末：渡劫 Boss 或迁徙
  → 据点部分清空；仙命 / 功法树 / 弟子羁绊永久保留
  → 下一季带着业力残局开场
```

失败不是删档：门派残破 + 牌库带着业力进入下一季。

## 4. 三大支柱

### 4.1 劫季（时间压力）

| 天象 | 经营 | 战斗 | 风险 |
| --- | --- | --- | --- |
| 雷月 | 渡劫材料产出↑ | 伤害与破防↑ | 野遇更凶；渡劫检定加严 |
| 雾月 | 跑商/潜行事件↑ | 费用波动（部分牌 +1/-1） | 情报不准；迷路类事件 |
| 血月 | 秘境掉落↑ | 吸血/爆发牌强化 | 失败掉小境界或残业力 |

每季固定天数（建议 24～36 个大地图行动点）。季末必须结算渡劫或迁徙。

### 4.2 危门经营（卡组工厂）

建筑不产空洞金币，产「可进库的东西」：

- 灵田 → 药材
- 丹房 → 临时药剂牌 / 修为
- 铸牌斋（核心）→ **牌胚**（带流派底色的未完成卡）
- 藏经阁 → 仙命候选刷新
- 外门寮 → 弟子（活卡包：固定小卡组外援）

进秘境前：**卡组锁定**。秘境内可拾取新牌，部分「季限牌」离开秘境消失。

### 4.3 业力牌（差异化钩子）

业力是「天道记账」。来源：借宝、杀人、逃劫、受门派恩惠、黑市交易。

三类：

1. **即时业**：抽到即结算（免费，可好可坏）
2. **负业**：回合结束仍在手则触发惩罚
3. **赌业**：保留可换成高回报，失败加厚业力库

业力库与主卡组分流或标记同一库（实现选「标记同一库」以降低规则成本）。数量一期控制在 **12 张原型**。

## 5. 战斗定位

- 回合制卡牌，保持原作 Flame/Hetu 卡牌战骨架
- 费用 / 抽牌 / 弃牌堆：对齐现代肉鸽习惯（原版 TODO 已有方向）
- 敌人意图可读（学 StS，不学黑盒数值）
- 流派底色（原版已有规划）：中立白 / 悟道绿 / 御剑蓝 / 锻体红 / 法身橙 / 炼魂黑

一期不做自动战斗 AI 深度重写；优先「玩家回合决策密度」。

## 6. 永久成长（季间保留）

- 仙命：突破时三选一（被动或构筑轴）
- 功法树节点（少量，避免肝）
- 弟子羁绊等级
- 图鉴解锁的牌胚配方

不保留：当季据点等级的大部分、秘境临时牌、未消化的高危业力（可转化为永久诅咒槽，上限 3）。
